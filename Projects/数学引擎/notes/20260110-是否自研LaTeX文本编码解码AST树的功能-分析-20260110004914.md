# 20260110-是否自研LaTeX文本编码解码AST树的功能-分析-20260110004914



因为这个项目是符号计算引擎，需要能够输入一个latex风格的文本，然后编码成我的引擎的内部数据结构，用于计算，最后再解码成latex渲染。你是否建议我自己设计一个latex编码解码器，还是用现成的？

我思考了一些自研的方法[[解析 LaTeX 为 Token 树结构-笔记-20260527-001]]，但是我越想越觉得这个自研不简单。设计规则很多。

这样子，要不直接调用 sympy的解析器，解析成AST。后续再根据AST编码成自己的引擎的数学符号计算系统的数据结构。

因此，现有的自研的`latex_parser.py`不再开发，我已经重命名为`latex_parser_developed_by_myself_but_useless.py`。请你对其中文件文档补充几句话说明这是自研的，但是已经弃用，改用 SymPy 自带的 LaTeX 编码器、解码器实现对 AST 树的编码解码过程。
