# CNKI导出落盘与受限全文规则-任务-20260308-001

## 1. 任务背景

本任务对应第三步执行目标：接 Zotero、RIS 落盘和受限全文目录规则。

本轮重点不是把所有第三方系统一次接通，而是先把以下内容接到当前仓库规范里：

1. RIS 落盘。
2. GB/T 引用落盘。
3. 原始导出 JSON 落盘。
4. 文献 manifest 同步。
5. Zotero Connector 推送入口。
6. 受限全文目录路径规则。

## 2. 可行性分析

当前仓库本身已经有：

1. `references/normal/bib/`
2. `references/normal/manifest/`
3. `references/origin/ai_web_subscription_files/`
4. `references/origin/ai_web_subscription_meta/`

因此可直接在不破坏现有结构的情况下把 CNKI 导出产物接进去。

## 3. 计划步骤

1. 为 CNKI 导出增加 RIS、GB/T、JSON 写盘。
2. 为文献 manifest 增加 CNKI 条目写入逻辑。
3. 为无全文条目写入缺全文清单。
4. 为 Zotero Connector 增加本地推送入口。
