# 学术事务调度与三库开发实施-任务-20260307-009

## 1. 本轮目标

1. 将能够复用 `academicresearch_kit` 现有能力的 skill 脚本尽量收口到 `academicresearch_kit/skills/`。
2. 将相对独立、可复用的公共辅助逻辑整理到 `academicresearch_kit/tools/`。

## 2. 可行性分析

1. 当前 `academicresearch_kit` 已经具备可直接复用的三类能力：workflow 执行、项目初始化、检索治理。
2. 这些能力适合优先映射到 `ark-workflow-executor`、`project-bootstrap`、`api-data-fetch` 三个 skill。
3. 其余多数 skill 当前以方法论和流程规范为主，仓库内尚无对应业务执行代码，适合先在包内补 markdown 版说明与待接入清单。
4. `main.py` 中的路径解析、JSON 读取、dispatch map 读取等逻辑相对独立，适合收口到 `academicresearch_kit/tools/`。
