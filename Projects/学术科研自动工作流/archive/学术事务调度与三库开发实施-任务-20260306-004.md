## 6. 实施结果

### 6.1 核对结论

对照总计划与 `001/002/003` 三个 task，确认本轮实际缺失/错误如下：

1. `database/tasks`、`database/references`、`database/knowledge` 整体丢失。
2. `config/scheduler/` 整体丢失。
3. `academicresearch_kit/cli/` 中只剩 `scheduler.py`，其余 `taskdb_bootstrap.py`、`taskdb_validate.py`、`taskdb_replay.py`、`retrieval.py` 缺失。
4. `academic_research_toolbox/__init__.py` 与 `academic_research_toolbox/main.py` 丢失，导致：
	- `academicresearch_kit.__init__` 中 `ark.run` / `ark.main` 兼容导出失效。
	- `pyproject.toml` 中 `academic-research-kit = academic_research_toolbox.main:main` 的主命令目标失效。
5. 项目根 `pyproject.toml` 丢失，导致无法重新执行 `pip install -e .`。

### 6.2 已补齐内容

1. 恢复兼容包：
	- `academic_research_toolbox/__init__.py`
	- `academic_research_toolbox/main.py`
2. 恢复 CLI：
	- `academicresearch_kit/cli/__init__.py`
	- `academicresearch_kit/cli/taskdb_bootstrap.py`
	- `academicresearch_kit/cli/taskdb_validate.py`
	- `academicresearch_kit/cli/taskdb_replay.py`
	- `academicresearch_kit/cli/retrieval.py`
3. 增强 `academicresearch_kit/tasking_db/bootstrap.py`，使其在恢复模板时同步创建：
	- `database/tasks/snapshots/`
	- `database/references/unit_db/`
	- `database/references/vector_index/`
	- `database/knowledge/notes/`
	- `database/knowledge/vector_index/`
4. 恢复项目根 `pyproject.toml`，重新声明发行名、依赖、包发现与 CLI 入口。
5. 通过 `ark-taskdb-bootstrap --project-root .` 重新落盘以下模板：
	- `config/scheduler/edge_weights.json`
	- `config/scheduler/selection_policy.json`
	- `config/scheduler/guard_policy.json`
	- `config/scheduler/dispatch_map.json`
	- `database/tasks/*`
	- `database/references/*`
	- `database/knowledge/*`
