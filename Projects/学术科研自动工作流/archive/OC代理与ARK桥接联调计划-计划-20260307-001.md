# OC代理与ARK桥接联调计划-计划-20260307-001

## 1. 背景

在 `report-OC代理与ARK技能对齐开发汇报-20260307-001.md` 对应的开发完成后，当前仓库已经补齐了：

1. ARK 新增 5 个 skill 包装模块。
2. OC 新增 5 个 skill 目录说明与多组脚本桥接。
3. OC Agents 增补 `task-state-manager`、`transaction-state-manager`，并更新了协同矩阵。
4. `academicresearch_kit/docs` 已同步为当前真实实现。

下一轮重点不再是继续补文档壳子，而是统一联调、回放和补最关键的状态写回闭环。

## 2. 目标

1. 验证 9 条 OC Skill -> ARK Skill 的调用链是否可执行。
2. 验证 `scheduler-dispatch`、`retrieval-governance`、`taskdb-*` 三条基础主链路。
3. 把 `task-state-manager`、`transaction-state-manager` 从“代理契约”推进到“可调用状态写回动作”。
4. 为后续文献管理与知识管理模块开发准备稳定底座。

## 3. 范围

### 3.1 本轮应做

1. 脚本级烟雾测试。
2. 最小调度链路联调。
3. taskdb 初始化、校验、回放联调。
4. 文档与 API 输出结果核对。

### 3.2 本轮不做

1. 大规模新增高层研究技能。
2. DiD/RDD 或实证四件套的完整统计实现。
3. 文献向量索引与知识图谱的工程化扩展。

## 4. 分步计划

### 步骤 1：统一脚本联调

1. 逐个验证以下脚本：
- `run_ark_workflow.py`
- `run_project_bootstrap.py`
- `run_api_data_fetch.py`
- `run_model_routing_dispatch.py`
- `run_retrieval_governance.py`
- `run_scheduler_dispatch.py`
- `run_taskdb_bootstrap.py`
- `run_taskdb_validate.py`
- `run_taskdb_replay.py`
2. 记录每个脚本的最小输入与输出结构。

验收：9 个脚本至少在最小参数下能返回结构化 JSON 或明确报错。

### 步骤 2：调度闭环联调

1. 使用 `scheduler-dispatch` 触发一次文献检索型事务。
2. 校验 `DispatchEventLogger` 是否写入 `logs/run/ark_scheduler_events.jsonl`。
3. 校验 `selection`、`guard_decision`、`receipt` 字段完整性。

验收：至少完成 1 条 `调度 -> 派发 -> 记录` 最小闭环。

### 步骤 3：检索治理联调

1. 使用开放文献请求验证 `PASS -> reference_ingestion`。
2. 使用闭源请求验证 `BLOCKED -> manual_review_queue`。
3. 检查 `bundle` 字段是否满足后续入库需要。

验收：开放与闭源两种状态均返回结构化 bundle。

### 步骤 4：taskdb 联调

1. 先用 `taskdb-bootstrap` 生成模板。
2. 用 `taskdb-validate` 检查模板完整性。
3. 用 `taskdb-replay` 验证空日志和非空日志两类回放结果。

验收：初始化、校验、回放三步均可串联执行。

### 步骤 5：状态管理动作补全

1. 为 `task-state-manager` 设计最小 task 写回入口。
2. 为 `transaction-state-manager` 设计最小 transaction/event 写回入口。
3. 优先复用现有 `tasking_db` 和 `scheduler_core` 模块，不引入第二套状态存储。

验收：至少能记录任务阶段状态与单轮事务事件状态。

## 5. 风险

1. 当前脚本层虽然已补齐，但参数风格尚未完全统一。
2. `model-routing-dispatch` 涉及外部接口，联调时容易引入外部依赖波动。
3. `task-state-manager` 与 `transaction-state-manager` 目前还只有代理契约，没有显式 Python skill。

## 6. 验收标准

1. 9 条 Skill 调用链完成统一调试。
2. `scheduler-dispatch`、`retrieval-governance`、`taskdb-*` 三类主链至少各跑通一条样例。
3. `academicresearch_kit/docs/API手册.md` 与实际调用参数保持一致。
4. 任务状态与事务状态存在最小可写回方案。
