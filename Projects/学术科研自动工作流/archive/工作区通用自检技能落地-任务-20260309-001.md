# 工作区通用自检技能落地-任务-20260309-001

## 1. 任务背景

为避免项目运行期间出现“浏览器缓存和临时文件落到根目录”这类隐患，需要一个通用自检机制：

1. 项目初始化时全面自检。
2. 每个事务前快速自检。
3. 自检结果覆盖事务、智能体、技能三个维度。

## 2. 可行性分析

当前仓库已具备：

1. 统一技能接入层（`academicresearch_kit/skills/`）。
2. OpenCode 技能脚本包装规范（`.opencode/skills/*/scripts/*.py`）。
3. 运行日志目录（`.opencode/logs/`）。

因此可新增一个通用 skill 来承接全检/快检。

## 3. 计划与实施

本次已完成：

1. 新增 ARK 自检 skill：`academicresearch_kit/skills/workspace_sanity_check.py`。
2. 新增 OpenCode skill：
   - `.opencode/skills/workspace-sanity-check/SKILL.md`
   - `.opencode/skills/workspace-sanity-check/scripts/run_workspace_sanity_check.py`
3. 新增命令文档：`.opencode/commands/run-workspace-sanity-check.md`。
4. 顶层 API 导出：`academicresearch_kit/skills/__init__.py`、`academicresearch_kit/__init__.py`。

## 4. 当前能力

该技能支持：

1. `full`：全面检查根目录污染、技能契约完整性、事务/智能体/技能覆盖和 `.gitignore` 规则。
2. `fast`：轻量检查高风险项，适合事务前执行。
3. 可选自动迁移根目录浏览器数据到：`sandbox/runtime/web_brower_profiles/cnki_main`。
4. 输出 JSON 与 Markdown 报告到 `.opencode/logs/workspace_sanity/`。

补充自动化策略：

1. 项目启动前全检：`project-bootstrap` 默认自动执行 `full` 自检。
2. 每个事务前快检：通过 `academicresearch_kit.skills.__init__` 的统一包装，对事务型 skill 调用自动注入 `fast` 自检。
3. 快检默认不落盘报告（`write_report=False`），避免高频运行产生性能和日志负担。
4. 不启用“每日自动全检”，仅保留：
   - 项目启动前自动全检
   - 每事务前自动快检
   - 人工手动全检（按需）

## 5. 建议流程

1. 项目启动前：运行一次 `full + auto_migrate`。
2. 每个事务前：运行一次 `fast`。
3. 每日首次运行或发版前：再跑一次 `full`。

按当前治理口径，建议改为：

1. 项目启动前：自动 `full + auto_migrate`（已落地）。
2. 每个事务前：自动 `fast`（已落地）。
3. 手动复检：仅在需要时运行 `full`，不做每日自动全检。
