# ES_notebook卡片化整理队列

> [!NOTE]
> 本队列用于把 ES_notebook 的非 Projects 内容按卡片笔记法分批整理。`Projects/` 子项目只做外部索引和摘录，不移动内部文件。

## Batch 01：闪念入口收束

- [ ] 从 `Collection` 选 20 条高价值笔记，标记为概念卡、机制卡、理论入口卡、项目链接或归档候选。
- [ ] 对 `DailyNotes` 与 `Weekly Notes` 中仍有长期价值的想法建立 Notes 摘录卡。
- [x] 为 Collection 建立状态字段或清单：raw / processing / permanent / project-link / archived。

## Batch 02：永久卡主仓强化

- [x] 为 `Notes` 建立概念、机制、术语、经验判断四类索引。
- [ ] 每张新增永久卡保留来源链接、相关 Theory、相关 Projects 外部链接。
- [ ] 处理 `Notes` 中非 md 附件清单，只登记，不直接移动嵌入附件。

## Batch 03：Theory 入口卡化

- [ ] 把 `Theory` 中的系统总纲页标记为入口卡。
- [ ] 对单点概念只建立 Notes 反链，不搬动 Theory 原文。
- [ ] 为 ES / ECS / CIS / LMS / AWS 建立入口卡清单。

## Batch 04：Affairs 过程卡化

- [ ] 将 `Operate`、`Analyse`、`Design`、`Develope`、`Experiments` 的方法类内容登记为过程卡候选。
- [ ] 在 `Affairs` 中建立流程卡、模板卡、检查清单。
- [ ] 与 Projects 相关的流程只保留原位链接。

## Batch 05：归档与回顾

- [x] 非 Projects sidecar 已无剩余。
- [ ] 每批整理后补充 `archives/2026-05-17-整理台账.md`。
- [ ] 每周回顾 Collection 与新增永久卡反链。
