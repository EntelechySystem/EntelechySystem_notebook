可以，用你现在的接口，两种路子都是可行的，只是适用场景和训练方式有点差别：

---

### 1\. 用 `redistribution_mode="custom"` \+ 用户自定义分配函数

**特点：**

- 你写一个 allocator 函数，签名已经约定好了，大致是：

  ```python
  def my_allocator(failed_node: int, targets: np.ndarray, model_obj) -> np.ndarray:
      # 返回 shape == (len(targets),) 的权重向量
      ...
  ```

- 在这个函数内部，你可以：
  - 读取 `model_obj.state / load / capacity / adjacency` 等全局信息；
  - 决定对当前 `failed_node` 的负载，在 `targets` 之间怎么分配；
  - 这就很适合「**策略网络在线决策**」式的强化学习。

**适合的 RL 用法：**

- 把 allocator 当作「环境 \+ agent 的接口」：
  - 状态 state：从 `model_obj` 里提取你关心的特征（局部邻域信息、当前负载、剩余容量等）；
  - 动作 action：一个在 simplex 上的分布（对 `targets` 的分配比例向量），可用策略网络输出；
  - allocator 只负责「把 agent 输出的动作（权重向量）塞回模型」。

**优点：**

- 很灵活，动作可以依赖全局信息、历史信息等；
- 方便做在线学习、策略迭代、actor\-critic 等。

---

### 2\. 用 `redistribution_mode="external_weights"` \+ 训练好的静态权重矩阵

**特点：**

- 你给模型一个 `redistribution_weights: np.ndarray`，形状是 `(N, N)`；
- 行 `i` 表示「节点 i 失效时，向其它节点的分配偏好权重」；
- 这更像是一个**固定策略表**，不随时间和状态改变（除非你在外部不停更新这个矩阵）。

**适合的 RL 用法：**

- 比较适合作为「**离线/预训练后的策略参数**」：
  - 比如你先用 RL 训练出一个参数矩阵（或从策略网络抽取某种平均行为），训练完毕后固化成 `W`；
  - 仿真时就不再需要在线调用策略网络了，只用 `external_weights` 直接查表分配。

**优点：**

- 运行时非常快，只有简单查表，不调用复杂网络；
- 适合「先训练，再部署」的场景。

---

### 3\. 结合方式建议

- **做 RL 训练阶段**：更推荐用 `custom` 模式：
  - allocator 里调用你的策略网络，产生动作（权重向量）；
  - 按 episode 跑完整个级联过程，收集回报，更新网络参数。
- **训练结束后部署/对比基线**：
  - 可以把最终学到的策略固化为：
    - 直接保留 `custom` \+ 网络（在线决策），或
    - 抽取为一个 `N×N` 的静态权重矩阵，改用 `external_weights` 做快速评估。

总结：  
- 想做「真正的强化学习训练与在线决策」：用 `custom` 模式的用户自定义分配函数，在函数里挂上 RL 策略。  
- 想做「用训练好的结果当成固定策略运行」：用 `external_weights`，把训练好的（或从策略中抽取的）权重当静态矩阵传进去即可。

import numpy as np
from typing import Dict, Any, Optional

STATE_NORMAL = 0
STATE_FAILED = 1


class CascadeFailuresModel_SingleMechanism:
    """
    单层单机制级联失效模型（负载重分配），**仅负责演化，不做统计分析**。

    - 只维护运行所需的原始量：state, load, capacity；
    - 不在内部记录历史统计指标，不计算鲁棒性、压力等分析量；
    - run() 只负责时间推进，可选返回原始历史快照，由外部分析模块事后处理。
    """

    def __init__(self,
                 adjacency: np.ndarray,
                 N: int,
                 steps: int = 200,
                 seed: Optional[int] = None,
                 load_redundancy: float = 0.2,
                 early_stop_patience: int = 10,
                 redistribution_mode: str = "average",
                 redistribution_weights: Optional[np.ndarray] = None,
                 random_dirichlet_alpha: float = 1.0) -> None:
        """
        初始化单机制级联失效模型对象。

        Args:
            adjacency: 网络邻接矩阵，形状为 (N, N)。
            N: 节点数量。
            steps: 最大仿真步数。
            seed: 随机数种子。
            load_redundancy: 负载冗余比例，用于初始化容量。
            early_stop_patience: 早停耐心值，若连续多少步无状态变化则提前终止。
            redistribution_mode: 负载重分配模式，支持：
            redistribution_weights: 外部提供的分配权重矩阵，仅在 mode="external_weights" 时使用。
            random_dirichlet_alpha: Dirichlet 分布的 alpha 参数，仅在 mode="random" 时使用。
        """
        self.rng = np.random.default_rng(seed)
        self.N = N
        self.steps = steps
        self.adjacency = adjacency
        self.load_redundancy = load_redundancy
        self.early_stop_patience = early_stop_patience

        # 运行期原始状态量（只保留机制直接需要的量）
        self.state = np.zeros(N, dtype=np.int8)
        self.load = np.zeros(N, dtype=float)
        self.capacity = np.zeros(N, dtype=float)

        # 分配策略相关
        self.redistribution_mode = redistribution_mode
        self.redistribution_weights = redistribution_weights
        self.random_dirichlet_alpha = random_dirichlet_alpha
        self.custom_allocator = None

        # 早停判断
        self._no_change_steps = 0

    def set_custom_allocator(self, func) -> None:
        """设置自定义分配回调函数。"""
        self.custom_allocator = func

    def initialize(self,
                   load_init_max: float = 0.7,
                   use_degree: bool = True) -> None:
        """
        初始化容量与负载。

        - 若 use_degree=True，则按节点度归一生成基础容量；
        - 初始负载 = 容量 * U(0, load_init_max)。
        """
        base = np.ones(self.N, dtype=float)
        if use_degree:
            deg = self.adjacency.sum(axis=1)
            if deg.max() > 0:
                base = deg / deg.max()
        self.capacity = base * (1.0 + self.load_redundancy)
        self.load = self.capacity * self.rng.uniform(0, load_init_max, size=self.N)

    def mechanism_load_redistribution(self) -> None:
        """
        单步负载重分配机制（模型本体）

        对所有失效节点，将其负载按指定策略分配给邻居正常节点。分配策略包括：
        - "average": 平均分配给所有邻居正常节点；
        - "adjacency_weight": 按邻接矩阵权重分配给邻居正常节点；
        - "capacity_slack": 按邻居正常节点的容量剩余分配（capacity - load）；
        - "random": 按 Dirichlet 分布随机分配；
        - "external_weights": 按外部提供的权重矩阵分配；
        - "custom": 使用用户自定义的分配函数分配。

        Args:
            无

        Returns:
            无

        Examples:
            对于不同的分配策略。我们给出了几种使用示例：

            --------
            下面给出若干极简的“抽象网络”示例，只演示不同分配模式的用法，不涉及任何具体学科场景。

            基本准备：构造一个 3 个节点的简单网络，其中节点 0 已经失效，
            需要把它的负载在节点 1 和 2 之间分配：

            >>> import numpy as np
            >>> from Projects.cascading_failures.models.cascading_failures_单机制 import (
            ...     CascadeFailuresModel_SingleMechanism, STATE_NORMAL, STATE_FAILED
            ... )
            >>> A = np.array([
            ...     [0, 1, 1],
            ...     [1, 0, 0],
            ...     [1, 0, 0],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(adjacency=A, N=3, steps=1)
            >>> model.capacity[:] = 1.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0      # 节点 0 持有总负载 10
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED  # 只有节点 0 失效

            1）average 模式：平均分配
            ~~~~~~~~~~~~~~~~~~~~~~~~~

            >>> model.redistribution_mode = "average"
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.mechanism_load_redistribution()
            >>> model.load
            array([0., 5., 5.])  # 失效节点 0 的负载 10 被平均分给邻居 1 和 2

            2）adjacency_weight 模式：按邻接权重比例分配
            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            将邻接矩阵改成不同权重，例如对节点 1 的权重为 1，对节点 2 的权重为 3：

            >>> A = np.array([
            ...     [0, 1, 3],
            ...     [1, 0, 0],
            ...     [3, 0, 0],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(adjacency=A, N=3, steps=1)
            >>> model.capacity[:] = 1.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.redistribution_mode = "adjacency_weight"
            >>> model.mechanism_load_redistribution()
            >>> model.load
            array([0., 2.5, 7.5])  # 1 : 3 的权重比例分配

            3）capacity_slack 模式：按剩余容量比例分配
            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            假设两条邻居的剩余容量不同（比如节点 1 还有较大空间，节点 2 已经比较满）：

            >>> A = np.array([
            ...     [0, 1, 1],
            ...     [1, 0, 0],
            ...     [1, 0, 0],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(adjacency=A, N=3, steps=1)
            >>> model.capacity[:] = 10.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0            # 失效节点负载 10
            >>> model.load[1] = 1.0             # 节点 1 已有负载 1，剩余容量 9
            >>> model.load[2] = 8.0             # 节点 2 已有负载 8，剩余容量 2
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.redistribution_mode = "capacity_slack"
            >>> model.mechanism_load_redistribution()
            >>> model.load
            array([0.,  1.0 + 10 * 9/11,  8.0 + 10 * 2/11])

            4）random 模式：按 Dirichlet 随机比例分配
            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            在 random 模式下，分配比例由 Dirichlet 分布随机生成，每次运行结果可能不同：

            >>> A = np.array([
            ...     [0, 1, 1],
            ...     [1, 0, 0],
            ...     [1, 0, 0],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(adjacency=A, N=3, steps=1, seed=123)
            >>> model.capacity[:] = 1.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.redistribution_mode = "random"
            >>> model.random_dirichlet_alpha = 1.0  # 均匀 Dirichlet
            >>> model.mechanism_load_redistribution()
            >>> model.load.sum()
            10.0  # 总负载守恒，但在节点 1 和 2 之间的分配比例是随机的

            5）external_weights 模式：使用外部给定的权重矩阵
            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            可以事先提供一个 N×N 的权重矩阵，每一行给出对应失效节点向邻居的分配偏好：

            >>> A = np.array([
            ...     [0, 1, 1],
            ...     [1, 0, 0],
            ...     [1, 0, 0],
            ... ], dtype=float)
            >>> W = np.array([
            ...     [0, 0.2, 0.8],   # 节点 0 失效时，向节点 1: 20%，向节点 2: 80%
            ...     [0, 0,   0  ],
            ...     [0, 0,   0  ],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(
            ...     adjacency=A, N=3, steps=1, redistribution_mode="external_weights",
            ...     redistribution_weights=W,
            ... )
            >>> model.capacity[:] = 1.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.mechanism_load_redistribution()
            >>> model.load
            array([0., 2., 8.])  # 严格按照外部给定 0.2 : 0.8 比例分配

            6）custom 模式：使用用户自定义的分配函数
            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

            用户可以提供一个回调函数，自行决定任意失效节点在邻居之间的分配比例：

            >>> def my_allocator(failed_node: int, targets: np.ndarray, model_obj) -> np.ndarray:
            ...     # 举例：总是把失效节点负载全部分配给索引最小的那个邻居
            ...     weights = np.zeros_like(targets, dtype=float)
            ...     weights[0] = 1.0
            ...     return weights
            ...
            >>> A = np.array([
            ...     [0, 1, 1],
            ...     [1, 0, 0],
            ...     [1, 0, 0],
            ... ], dtype=float)
            >>> model = CascadeFailuresModel_SingleMechanism(
            ...     adjacency=A, N=3, steps=1, redistribution_mode="custom",
            ... )
            >>> model.set_custom_allocator(my_allocator)
            >>> model.capacity[:] = 1.0
            >>> model.load[:] = 0.0
            >>> model.load[0] = 10.0
            >>> model.state[:] = STATE_NORMAL
            >>> model.state[0] = STATE_FAILED
            >>> model.mechanism_load_redistribution()
            >>> model.load
            array([0., 10., 0.])  # 全部分给 targets[0]（这里是节点 1）

        """
        failed_nodes = np.where(self.state == STATE_FAILED)[0]
        if failed_nodes.size == 0:
            return

        A = self.adjacency
        incr = np.zeros(self.N, dtype=float)

        for n in failed_nodes:
            nbrs = np.where(A[n] > 0)[0]
            nbrs = nbrs[nbrs != n]
            if nbrs.size == 0:
                continue

            targets = nbrs[self.state[nbrs] == STATE_NORMAL]
            if targets.size == 0:
                continue

            total_load = self.load[n]
            if total_load <= 0:
                continue

            mode = self.redistribution_mode
            weights: np.ndarray

            if mode == "average":
                weights = np.ones(targets.size, dtype=float)
            elif mode == "adjacency_weight":
                weights = A[n, targets].astype(float)
            elif mode == "capacity_slack":
                slack = np.maximum(self.capacity[targets] - self.load[targets], 0.0)
                weights = slack
            elif mode == "random":
                alpha = np.full(targets.size, self.random_dirichlet_alpha, dtype=float)
                weights = self.rng.dirichlet(alpha)
            elif mode == "external_weights":
                if self.redistribution_weights is None:
                    weights = np.ones(targets.size, dtype=float)
                else:
                    weights = self.redistribution_weights[n, targets].astype(float)
            elif mode == "custom":
                if self.custom_allocator is None:
                    weights = np.ones(targets.size, dtype=float)
                else:
                    w = self.custom_allocator(n, targets, self)
                    if w is None or len(w) != targets.size:
                        weights = np.ones(targets.size, dtype=float)
                    else:
                        weights = np.array(w, dtype=float)
            else:
                weights = np.ones(targets.size, dtype=float)

            # 统一归一化处理
            weights = np.maximum(weights, 0.0)
            sum_w = float(np.sum(weights))
            if sum_w <= 0:
                portion = total_load / targets.size
                incr[targets] += portion
            else:
                portion_vec = total_load * (weights / sum_w)
                incr[targets] += portion_vec

        # 应用增量 & 清零失效节点负载
        self.load += incr
        self.load[failed_nodes] = 0.0

        # 过载判定
        overload_mask = (self.state == STATE_NORMAL) & (self.load > self.capacity)
        self.state[overload_mask] = STATE_FAILED

    def run(self,
            is_record_history: bool = True) -> Dict[str, Any]:
        """
        执行仿真主循环，只负责推进级联机制。

        若 is_record_history=True，则返回每步的原始快照：
        - states[t]: 第 t 步之后的 state 向量
        - loads[t]:  第 t 步之后的 load 向量
        - capacities[t]: 第 t 步之后的 capacity 向量（通常不变）

        """
        patience_limit = self.early_stop_patience

        states_hist = []
        loads_hist = []
        caps_hist = []

        if is_record_history:
            states_hist.append(self.state.copy())
            loads_hist.append(self.load.copy())
            caps_hist.append(self.capacity.copy())

        for _ in range(self.steps):
            prev_state = self.state.copy()

            self.mechanism_load_redistribution()

            changed = not np.array_equal(self.state, prev_state)
            if changed:
                self._no_change_steps = 0
            else:
                self._no_change_steps += 1

            if is_record_history:
                states_hist.append(self.state.copy())
                loads_hist.append(self.load.copy())
                caps_hist.append(self.capacity.copy())

            if self._no_change_steps >= patience_limit:
                break

        result: Dict[str, Any] = {
            "final_state": self.state.copy(),
            "final_load": self.load.copy(),
            "final_capacity": self.capacity.copy(),
        }
        if is_record_history:
            result["states"] = np.stack(states_hist, axis=0)
            result["loads"] = np.stack(loads_hist, axis=0)
            result["capacities"] = np.stack(caps_hist, axis=0)
        return result
