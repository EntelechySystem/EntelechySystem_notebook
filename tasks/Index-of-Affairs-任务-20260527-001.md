# Index-of-Affairs-任务-20260527-001

> [!NOTE]
> Affairs 是 ES_notebook 的可复用事务层，用来承接方法、流程、模板、分析、设计、开发与实验类内容。当前仅建立入口，不移动既有正文笔记。

## 1. 目标职责

- 承接从 `Operate`、`Analyse`、`Design`、`Develope`、`Experiments` 中逐步收束出来的通用过程性内容。
- 与 `Projects` 区分：Projects 保留具体项目推进，Affairs 保留可跨项目复用的事务方法。
- 与 `Notes` 区分：Notes 保留实体知识卡，Affairs 保留行动流程、模板和操作方法。
- 与 `Theory` 区分：Theory 保留系统总纲和框架入口，Affairs 保留“怎么做”的过程层。

## 2. 计划承接入口

- Analyse：分析流程、分析模板、问题拆解方法。
- Design：设计流程、结构设计模板、图示规范。
- Develope：开发流程、脚本整理、实现步骤。
- Experiments：实验流程、验证清单、试运行记录。
- Operate：通用运作法、任务推进法、复盘流程。

## 3. 当前状态

- 已建立入口页。
- 尚未移动既有 md 正文。
- `Projects/` 已升级为子项目保护区，Affairs 只能通过链接、摘录、索引和外部清单管理项目材料，不移动、不改名、不合并项目内部文件。
- 后续迁移须优先通过 Obsidian 内移动能力执行，以保护双链和嵌入引用。
